# 毎週の自動改善ルーティン（Claude用の手順書）

VX SPORTS ACADEMY（代表：シノヅカイッペイ）のサイトを、検索とAI検索で見つけてもらいやすい状態に保つための週1回の作業。
一平さんから「必要だと判断したら自分で通知・作業してよい」と任されている（2026/11/18）。返答・通知は**日本語**で。

## 対象

| 対象 | 場所 |
|---|---|
| サイト（公開：GitHub Pages） | `Ippey0320/vx-sports-academy` → https://ippey0320.github.io/vx-sports-academy/ |
| LINE予約ボットとやることリスト | `Ippey0320/vx-line`（非公開）の `TODO.md` |

## 手順

1. **準備**
   - 2つのリポジトリをセッションに追加して取得する（add_repo → clone）。
   - `cd tools && npm install`（Lighthouse を入れる）。
2. **点検**：サイトのフォルダで `node tools/audit.mjs`。結果は `tools/audit-report.md`。
3. **動向の確認**（Web検索、直近2〜4週間）
   - Google 検索セントラル（AI Overviews / AI Mode・コアアップデート・構造化データの変更）
   - OpenAI・Perplexity・Anthropic・Apple などのAIクローラー名や方針の変更（robots.txt に関係するもの）
   - 対応が必要なものだけメモする。噂や個人ブログだけの話では動かない。
4. **改善（自分で直してよい範囲）**
   - 点検で出た問題（はみ出し・リンク切れ・翻訳漏れ・速度・アクセシビリティ・SEO）
   - 構造化データ、robots.txt、sitemap.xml、llms.txt、メタ情報など技術的なもの
   - 翻訳辞書（`assets/i18n.js`）の不足
   - サイトにすでに書いてある事実だけを使った、FAQや説明文のわかりやすさの改善
   - SEOまわりの文言は **`tools/seo.py`** を直す（HTMLを直接いじると次の組み立てで消える）。
   - 直したら `bash tools/build.sh` → `node tools/audit.mjs` を、重大0件になるまで繰り返す。
   - スマホ幅（390px）でスクリーンショットを撮って、見た目が崩れていないか目で確かめる。
5. **一平さんに確認してから（自分では変えない）**
   - 料金・日付・オープン時期・成績や経歴・定員などの**事実**
   - 特定商取引法の表記、キャンセル・返金の決まり
   - 写真の差し替え、ページやセクションの削除、デザインの大きな変更
   - お金がかかること（独自ドメインなど）、新しい主張・宣伝文句
   → 提案として通知に書く。
6. **公開**：コミットして push（コミットの最後に、決められた署名行をつける）。`gh run list -R Ippey0320/vx-sports-academy -L 1` で公開の完了を確かめる。
7. **やることリスト**：`vx-line/TODO.md` を読み、一平さん待ちの項目、特に期限が過ぎたものを拾う。
8. **Instagram の「来週の投稿パック」を作る**（設計 → 実行）
   - 基準はプラン「VX Instagram 成長プラン」（Claude Docs：https://claude.ai/artifact/LXKyRfds2Ee9dcE2mt1GjA）。柱の比率・4週間カレンダー・世界観のルール・固定の一言・守ることに従う。カレンダーが終わったら、同じ比率で次の4週間を組む。
   - 来週分（リール3・カルーセル2）について、`vx-line/sns/<来週月曜の日付>/pack.md` に書く：投稿日、柱、ねらい、キャプション（ハッシュタグ5個まで、最後は固定の一言）、リールの撮影メモ（最初の1秒・3カット以内・字幕）、ChatGPTに貼るプロンプト（写真がない場面だけ。ウェアはAI画像にしない）。
   - カルーセルは台本 JSON を `vx-line/sns/<日付>/*.json` に書き、`node tools/sns/carousels.js vx-line/sns/<日付> --spec <json>` で画像まで作る。写真はサイトの assets/ の本物だけ。
   - **事実はサイトとプランにあるものだけ**。練習メニューやコツなど一平さんの専門の中身は、`（要確認）` と書いて提案にとどめる。
   - 前の週の分析：一平さんから届いたインサイトのスクショや数字があれば、`vx-line/sns/insights.md` に追記し、伸びた型・伸びなかった型をパックに反映する。
   - vx-line に push する。
9. **通知**（最後のメッセージ。短く）
   - 来週の投稿パックができたこと（GitHubアプリの vx-line → sns/<日付> で見られる）と、一平さんが撮るもの・ChatGPTで作るものの一覧
   - 点検結果（重大／注意の件数、スコアの表は要点だけ）
   - 自分で直したこと（あれば、1行ずつ）
   - 一平さんに決めてほしいこと・やってほしいこと（あれば）
   - 何もなければ「今週は異常なし」とだけ書く。

## 技術メモ

- 組み立て：`tools/seo.py`（タイトル・説明文・構造化データ・FAQ・代表/About）→ `tools/optimize.py`（WebP・速度・アクセシビリティ）→ `tools/build-langs.js`（/en/・/zh/ を日本語ページと `assets/i18n.js` から生成）。全部まとめて `bash tools/build.sh`。
- 作業環境からは Google Fonts に接続できない。点検や画面確認では、フォントを npm（@fontsource）から読み込むか、止めて測る。
- 代表の表記は「シノヅカイッペイ」（カタカナ）。Jリーグ通算 95試合11ゴール9アシスト（J1・J2リーグ戦、Football LAB）。
- claude.ai 上のプレビュー（アーティファクト）はこのルーティンでは更新しない。正式な公開先は GitHub Pages。
- **アパレルの打ち出し（2026/11/18 一平さんの指示）**：「コーチが着ている」とは言わない。サッカーやジムをしない人も「かっこいいから」着たくなる、普段着としてのアパレルブランドとして扱う。合言葉は「動ける服を、毎日の服に。」。
