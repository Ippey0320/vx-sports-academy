# 毎週の自動改善ルーティン（Claude用の手順書）

VX SPORTS ACADEMY（代表：シノヅカイッペイ）のサイトを、検索とAI検索で見つけてもらいやすい状態に保つための週1回の作業。
一平さんから「必要だと判断したら自分で通知・作業してよい」と任されている（2026/11/18）。返答・通知は**日本語**で。

## 売り方の基準 ― 不変の基盤（2026/11/24〜・最優先・変えない）

サイトもインスタもLINEも新サービスも、すべて「脳の3段階」と「買う人の10の質問」に沿って作る（一平さんが2回指示。型は変えない）。毎週の作業の最初に framework.md の「出す前のチェック」で今週の成果物を確かめる。
基準の本文：`vx-line/marketing/framework.md`（決まったこと・数字・アカウントは `vx-line/marketing/brand.md`、動線は `funnel.md`）。サイトの該当ブロックは `tools/sales10.py` で管理（日英中）。
- 投稿パックの各投稿に「どの質問に答える投稿か（例：Q4・Q5）」を書き、1週間で10の質問をひと回りさせる。
- ChatGPTのプロンプトには「この画像は（質問）に答える1枚。3秒でわかるように、言いたいことは1つ」を必ず入れる。
- 質問3（証拠）は本物だけ。お客様の声や数字は作らない。「残りわずか」など事実でない期限も書かない。

## 手順

1. **準備**
   - 2つのリポジトリをセッションに追加して取得する（add_repo → clone）。
   - `cd tools && npm install`（Lighthouse を入れる）。
2. **点検**：サイトのフォルダで `node tools/audit.mjs`。結果は `tools/audit-report.md`。
3. **動向の確認**（Web検索、直近2〜4週間）
   - Google 検索セントラル（AI Overviews / AI Mode・コアアップデート・構造化データの変更）
   - OpenAI・Perplexity・Anthropic・Apple などのAIクローラー名や方針の変更（robots.txt に関係するもの）
   - 対応が必要なものだけメモする。噂や個人ブログだけの話では動かない。
4. **改善（自分で直してよい範囲）**
   - 点検で出た問題（はみ出し・リンク切れ・翻訳漏れ・速度・アクセシビリティ・SEO）
   - 構造化データ、robots.txt、sitemap.xml、llms.txt、メタ情報など技術的なもの
   - 翻訳辞書（`assets/i18n.js`）の不足
   - サイトにすでに書いてある事実だけを使った、FAQや説明文のわかりやすさの改善
   - SEOまわりの文言は **`tools/seo.py`** を直す（HTMLを直接いじると次の組み立てで消える）。
   - 直したら `bash tools/build.sh` → `node tools/audit.mjs` を、重大0件になるまで繰り返す。
   - スマホ幅（390px）でスクリーンショットを撮って、見た目が崩れていないか目で確かめる。
5. **一平さんに確認してから（自分では変えない）**
   - 料金・日付・オープン時期・成績や経歴・定員などの**事実**
   - 特定商取引法の表記、キャンセル・返金の決まり
   - 写真の差し替え、ページやセクションの削除、デザインの大きな変更
   - お金がかかること（独自ドメインなど）、新しい主張・宣伝文句
   → 提案として通知に書く。
6. **公開**：コミットして push（コミットの最後に、決められた署名行をつける）。`gh run list -R Ippey0320/vx-sports-academy -L 1` で公開の完了を確かめる。
7. **やることリスト**：`vx-line/TODO.md` を読み、一平さん待ちの項目、特に期限が過ぎたものを拾う。
8. **Instagram の「来週の投稿パック」を作る**（設計 → 実行 → 投稿の準備）
   - 基準はプラン「VX Instagram 成長プラン」（Claude Docs：https://claude.ai/artifact/LXKyRfds2Ee9dcE2mt1GjA）。柱の比率・4週間カレンダー・世界観のルール・固定の一言・守ることに従う。カレンダーが終わったら、同じ比率で次の4週間を組む。
   - **基本は「撮影なしの週」（2026/11/23 一平さんの指示：自分でできることは自動で）**。来週分（リール3・カルーセル2）を、Claude が**完成品まで**作る。
     - 写真はサイトの `assets/` にある本物だけ。文字はサイトとプランにある事実だけ。
     - カルーセル：`node tools/sns/carousels.js <出力> --spec <台本.json>`、リール：`node tools/sns/reel-spec.js <台本.json> <出力.mp4>`（台本は `vx-line/sns/<日付>/specs/` に保存）。
     - できたら確認用の画像（`*-check*.jpg` をタイル状に）を自分の目で見て、文字の切れ・はみ出し・事実を確かめる。確認用の画像はコミットしない。
     - 代表の試合写真（`founder.webp`）は、使用許可の確認（TODO の C）が終わるまで新しい素材に使わない。
     - AIで作った人物が写る素材（`football-kit`・ウェアのAI画像など）は `ai_label: true` にする。
   - 撮影が必要な企画・一平さんの専門の中身（練習メニュー・コツ・ビフォーアフター）は、一平さんが素材や中身をくれた週にまわす。`（要確認）` の下書きだけ pack.md の最後に残す。返事がなければ、事実だけで作れる代わりの案で進める。
   - 写真がない場面の画像は ChatGPT 担当。`OPENAI_API_KEY` がつながっていれば、`sns/<日付>/openai.json` を書いて Actions の openai-images を実行（MCP の actions_run_trigger）、できた画像の文字を必ずチェック。つながっていなければ、ChatGPT に貼るプロンプトを pack.md に書く（入れる文字を一字一句・黒白＋#D4FF2A・余白広め・太めのゴシック）。ウェアは必ず本物の商品写真を添付させ、形・色・ロゴを変えない。「COACH」という文字は使わない。
   - `vx-line/sns/<来週月曜>/pack.md`：一覧、キャプション（ハッシュタグ5個まで、最後は固定の一言）、ストーリーズ案。キャプションは `captions/<MMDD>.txt` にも保存。
   - **投稿の準備**：素材を `vx-sports-academy/ig/<日付>/` にコピーして公開し、`vx-line/sns/schedule.json` に `draft` で追加する（`sns/AUTOMATION.md`）。一平さんから「OK」が来たら `ok` にする。`auto_ok: true` なら返事がなくても予定時刻に出る。
   - 前の週の分析：`sns/insights.md`（月曜 8:40 に自動取得、未接続なら一平さんのスクショ）を読み、保存率・送信率が高かった型を増やす。`schedule.json` に `failed` や `manual` があれば通知に書く。
   - Instagram のトークンは60日で切れる。`GH_PAT` がなければ、つないだ日から50日たったら通知で入れ替えをお願いする。
   - 投稿が終わった週の `ig/<日付>/` は消してよい。
   - vx-line と vx-sports-academy に push する。
9. **通知**（最後のメッセージ。短く）
   - 来週の投稿パックができたこと（GitHubアプリの vx-line → sns/<日付> で見られる）、一平さんが確認して「OK」と返事するもの、手動で投稿するもの（AI情報ラベル・音源）
   - 点検結果（重大／注意の件数、スコアの表は要点だけ）
   - 自分で直したこと（あれば、1行ずつ）
   - 一平さんに決めてほしいこと・やってほしいこと（あれば）
   - 何もなければ「今週は異常なし」とだけ書く。

## 技術メモ

- 組み立て：`tools/seo.py`（タイトル・説明文・構造化データ・FAQ・代表/About）→ `tools/optimize.py`（WebP・速度・アクセシビリティ）→ `tools/build-langs.js`（/en/・/zh/ を日本語ページと `assets/i18n.js` から生成）。全部まとめて `bash tools/build.sh`。
- `tools/optimize.py` は何回組み立てても同じ結果になる（2026/11/23 に、フォントの <noscript> が組み立てのたびに重なっていた不具合を修正）。
- `tools/optimize.py` は何回組み立てても同じ結果になる（2026/11/23 に、組み立てのたびにフォントの `<noscript>` が重なっていた不具合を修正）。
- 作業環境からは Google Fonts に接続できない。点検や画面確認では、フォントを npm（@fontsource）から読み込むか、止めて測る。
- 代表の表記は「シノヅカイッペイ」（カタカナ）。Jリーグ通算 95試合11ゴール9アシスト（J1・J2リーグ戦、Football LAB）。
- claude.ai 上のプレビュー（アーティファクト）はこのルーティンでは更新しない。正式な公開先は GitHub Pages。
- **アパレルの打ち出し（2026/11/18 一平さんの指示）**：「コーチが着ている」とは言わない。サッカーやジムをしない人も「かっこいいから」着たくなる、普段着としてのアパレルブランドとして扱う。合言葉は「動ける服を、毎日の服に。」。商品名は「VX T-SHIRT／VX SHORTS／VX SOCKS」。キット名（COACH KIT・MOTIONなど）は使わない。
